# 🧮 Calculadora em C

## 📌 Sobre o projeto

Este projeto consiste em uma **calculadora desenvolvida em linguagem C**, criada com o objetivo de colocar em prática os conhecimentos que venho adquirindo durante meus estudos de programação.

## 🎯 Objetivos

* Praticar a linguagem C;
* Desenvolver e aprimorar minha lógica de programação;
* Aplicar na prática conceitos estudados durante os estudos;
* Aprender com a criação de um projeto desenvolvido do zero;
* Identificar e corrigir erros durante o desenvolvimento;
* Adquirir mais experiência com a linguagem C.

## ⚙️ Funcionalidades

A calculadora permite realizar operações matemáticas básicas, como:

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão

O programa recebe os valores informados pelo usuário, realiza a operação escolhida e apresenta o resultado.

## 🧠 Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos fundamentais da linguagem C, como:

* Variáveis;
* Tipos de dados;
* `scanf()` e `printf()`;
* Estruturas condicionais (`if` e `else`);
* Operadores matemáticos;
* Operadores relacionais;
* Entrada e saída de dados;
* Funções;
* Validação de entradas;
* Estrutura básica de um programa em C.

## 🛠️ Tecnologias utilizadas

* **Linguagem:** C
* **IDE/Editor:** Dev-C++
* **Versão utilizada:** 5.11
* **Sistema operacional:** Windows

## 📋 Pré-requisitos

Para executar o projeto, é necessário ter:

Dev-C++ instalado.

## 📖 Sobre o desenvolvimento

O projeto foi desenvolvido 100% individualmente, sem a participação de outros desenvolvedores, com o objetivo de praticar meus estudos em C e aprimorar minha lógica de programação.

Durante o desenvolvimento, também pude praticar a identificação e correção de erros, além de buscar soluções para os problemas encontrados ao longo da implementação.
